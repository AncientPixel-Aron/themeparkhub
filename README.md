# themeparkhub

A web application for exploring theme parks across the globe with detailed and up-to-date information for each park.

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Lint with [ESLint](https://eslint.org/)

```sh
npm run lint
```

### Type-Check, Compile and Minify for Production

```sh
npm run build
```

### Deploy to Github Pages after build

```sh
npm run deploy
```
